# Mengelola Data Dosen dan Mahasiswa (Import & Manual)

**Durasi:** 3–4 menit  
**Tipe Konten:** Screen Recording  
**Role:** Admin Prodi  

--- SCENE 1 ---
[SCREEN REC] Dashboard Admin Prodi beralih ke menu "Data Dosen & Mahasiswa". Dua tab utama terlihat: Tab Dosen dan Tab Mahasiswa.
[VO] Menyiapkan ratusan akun civitas akademika di awal semester tidak harus melelahkan. Admin Prodi di SALE memiliki kendali penuh untuk mengelola data dosen dan mahasiswa, baik satu per satu maupun secara massal.

--- SCENE 2 ---
[SCREEN REC] Admin Prodi berada di Tab "Dosen".
[CURSOR: action] Kursor mengklik tombol "+ Tambah Dosen Manual". Modal dialog muncul: mengisi Nama Lengkap beserta Gelar, NIDN/NIP, Email resmi kampus, dan password sementara. Klik "Simpan Dosen".
[ZOOM: area] Zoom ke modal form penambahan dosen manual.
[VO] Untuk menambah akun pengampu secara perorangan, klik Tambah Dosen Manual. Cukup masukkan nama, NIDN, email, serta password awal. Dosen akan langsung dapat login dan diarahkan untuk memperbarui kata sandinya secara aman.

--- SCENE 3 ---
[SCREEN REC] Kursor berpindah ke Tab "Mahasiswa".
[CURSOR: action] Kursor mengklik tombol "Unduh Template Excel (Mahasiswa)". File spreadsheet template terunduh.
[ZOOM: area] Zoom ke tombol Unduh Template Excel.
[VO] Bagaimana dengan ratusan mahasiswa baru? Manfaatkan fitur impor massal. Pertama, unduh template resmi Excel yang sudah disediakan. Format kolomnya sudah disesuaikan agar tidak terjadi kesalahan pemetaan data.

--- SCENE 4 ---
[SCREEN REC] Kursor mengklik tombol "Impor Data Mahasiswa". Modal impor muncul dengan area unggah berkas.
[CURSOR: action] Dosen/Admin menyeret file Excel yang telah terisi data mahasiswa (NIM, Nama, Email) ke kotak upload, lalu menekan "Proses Impor".
[ZOOM: area] Zoom ke modal upload file Excel dan proses validasi data.
[VO] Unggah kembali file Excel yang telah Anda lengkapi. Sistem SALE secara cerdas akan memvalidasi NIM dan email untuk mencegah terjadinya duplikasi data akun. Dalam hitungan detik, seluruh mahasiswa berhasil terdaftar ke dalam pangkalan data program studi.

--- SCENE 5 ---
[SCREEN REC] Daftar tabel mahasiswa ter-update dengan ratusan data baru. Kursor mencontohkan aksi ubah data dan tombol "Ekspor Data Pengguna" untuk backup spreadsheet.
[ZOOM: area] Zoom ke tombol Ekspor Data Pengguna di pojok kanan atas.
[VO] Seluruh akun kini aktif dan siap didistribusikan ke kelas perkuliahan. Anda juga dapat mengekspor kembali data pengguna kapan saja untuk sinkronisasi dengan pangkalan data universitas.

--- CATATAN PRODUKSI ---
- Gunakan data dummy nama dan NIM yang representatif (bukan data riil mahasiswa untuk privasi).
- Transisi antara Tab Dosen dan Tab Mahasiswa harus jelas.
- Visualisasi unduh dan unggah template Excel dibuat cepat dan responsif.
