# Monitoring Sistem, Storage, dan Backup Database

**Durasi:** 3–4 menit  
**Tipe Konten:** Screen Recording  
**Role:** Admin Sistem  

--- SCENE 1 ---
[SCREEN REC] Halaman "Monitoring Sistem" pada dashboard Administrator SALE. Kartu-kartu metrik realtime terlihat: Kapasitas Penyimpanan (Storage), Konsumsi Token AI, dan Status Backup Database.
[VO] Menjaga sistem tetap beroperasi tanpa henti memerlukan pengawasan proaktif. Melalui menu Monitoring Sistem di SALE, kesehatan server, beban penyimpanan, dan integritas data terpantau secara realtime.

--- SCENE 2 ---
[SCREEN REC] Sorotan pada Widget "Kapasitas Penyimpanan Sistem (Storage)".
[CURSOR: action] Kursor menunjuk progress bar kapasitas disk: ruang terpakai (Disk Used), ruang tersedia (Disk Free), dan total ukuran direktori penyimpanan berkas tugas & materi (`storage/app`). Terlihat pembaruan angka otomatis secara realtime.
[ZOOM: area] Zoom ke progress bar dan rincian kuota storage server.
[VO] Di bagian penyimpanan, Anda dapat memantau kapasitas hard disk server secara langsung. Sistem memperlihatkan persentase memori penyimpanan yang terpakai serta akumulasi berkas lampiran materi dan tugas mahasiswa. Pembaruan data berjalan otomatis tanpa perlu refresh berkala.

--- SCENE 3 ---
[SCREEN REC] Bagian "Metrik Penggunaan Asisten AI".
[CURSOR: action] Kursor menyorot grafik ringkasan token AI harian, rata-rata latensi permintaan, dan status koneksi model AI.
[ZOOM: area] Zoom ke grafik konsumsi token AI.
[VO] Ingin mengetahui seberapa sering mahasiswa berkonsultasi dengan asisten coding? Panel metrik AI menampilkan total token yang telah digunakan beserta riwayat request per hari, memudahkan Anda dalam merencanakan alokasi kuota token kampus.

--- SCENE 4 ---
[SCREEN REC] Bagian "Cadangan Database (Backup & Restore)".
[CURSOR: action] Admin mengklik tombol "Buat Cadangan Baru". Animasi loading berjalan singkat, lalu file backup SQL baru muncul di daftar riwayat. Kursor menunjukkan tombol unduh (.sql) dan tombol pulihkan (restore).
[ZOOM: area] Zoom ke tombol Buat Cadangan Baru dan baris file cadangan SQL.
[VO] Keamanan data adalah prioritas utama. Di bagian Backup Database, Anda dapat membuat cadangan pangkalan data SQL kapan saja hanya dengan satu klik. Unduh file cadangan tersebut ke penyimpanan dingin Anda, atau gunakan fitur pulihkan (restore) jika suatu saat dibutuhkan pemulihan darurat.

--- SCENE 5 ---
[SCREEN REC] Bagian "Log Aktivitas Sistem (Activity Log)".
[CURSOR: action] Scroll pada tabel log aktivitas yang mencatat aksi pengguna, alamat IP, dan waktu eksekusi.
[ZOOM: area] Zoom ke baris riwayat aktivitas sistem.
[VO] Seluruh aksi penting tercatat secara transparan di Log Aktivitas. Anda selalu mengetahui siapa yang melakukan pembaruan nilai, perubahan kurikulum, maupun pembuatan kelas baru demi menjaga auditabilitas sistem.

--- SCENE 6 ---
[VISUAL] Animasi logo SALE dengan teks "Sistem Tangguh. Data Terlindungi."
[VO] Dengan pemantauan cerdas dan proteksi berlapis, SALE siap mendukung operasional akademik kampus Anda secara andal sepanjang waktu.

--- CATATAN PRODUKSI ---
- Gerakan kursor tegas dan stabil saat menunjuk metrik teknis.
- Tunjukkan efek realtime polling (angka storage atau token yang ter-update halus) di Scene 2.
- Tone suara mantap, tenang, dan memberikan jaminan keamanan data (reassuring).
